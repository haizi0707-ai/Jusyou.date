重賞⭐️専用フィルター抽出アプリ

使い方
1. app.py と以下のCSVを同じフォルダに置く
   - 重賞別_プロンプト用ロジック辞書.csv
   - 重賞別_消し条件候補.csv
   - 重賞別_抽出サマリー.csv
2. Streamlitで起動
   streamlit run app.py
3. 対象重賞をタグ選択
4. 「②プロンプト作成」の内容をコピーしてChatGPTに貼り付け
5. ChatGPTが作成した該当CSVを「③該当CSV判定」に貼り付け
6. アプリが⭐️候補、準⭐️、見送りを判定
7. レース後に結果CSVを「④結果更新」に読み込み

注意
- オッズ・人気・予想印は予想判定には使わない設計です。
- 消し条件に該当した馬は原則⭐️から除外されます。
- 1位と2位の条件スコア差が小さい場合は、単独⭐️ではなく準⭐️/見送り扱いにします。
